# Flyer Studio

Flyer Studio est un éditeur de flyers statique, contenu dans un seul fichier `index.html` : choisissez un modèle (par défaut « Dance Night » Bachata), modifiez textes, photos et couleurs, puis exportez votre flyer directement depuis le navigateur, sur ordinateur comme sur mobile.

**Version en ligne :** https://veloster.github.io/flyer-studio/

Ce dépôt ne contient que la version publiée. Le code source et le guide d'utilisation se trouvent dans le package séparé.
